# Focus music

Drop focus-experience audio files in this directory.

Supported extensions:
- .mp3
- .wav
- .ogg
- .m4a
- .aac
- .flac

The playground discovers these files automatically and exposes them in:

Settings → Focus music → Focus song

The selected track is primed when the visitor clicks "Come Into Our World" and fades in when the focus camera settles.
